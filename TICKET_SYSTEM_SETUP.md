# Настройка системы продажи билетов

## Обзор

Система поддерживает два режима работы:
1. **Сбор контактов** (`collect_contacts`) - показывает форму для сбора email/телефонов посетителей
2. **Прямая продажа** (`ticket_sale`) - перенаправляет на внешнюю систему продажи билетов

## Быстрая настройка

### Файл конфигурации: `js/config.js`

```javascript
const TICKET_CONFIG = {
    mode: 'collect_contacts',           // Режим работы: 'collect_contacts' или 'ticket_sale'
    ticketSaleUrl: '',                  // URL страницы продажи билетов (для режима ticket_sale)
    googleScriptUrl: 'YOUR_GOOGLE_SCRIPT_URL_HERE'  // URL Google Apps Script (для режима collect_contacts)
};
```

---

## Режим 1: Сбор контактов (по умолчанию)

Используется когда билеты еще не продаются, но нужно собрать базу заинтересованных посетителей.

### Настройка:

```javascript
const TICKET_CONFIG = {
    mode: 'collect_contacts',
    ticketSaleUrl: '',
    googleScriptUrl: 'https://script.google.com/macros/s/YOUR_SCRIPT_ID/exec'
};
```

### Шаги настройки Google Sheets:

#### 1. Создание Google Таблицы

1. Откройте [Google Sheets](https://sheets.google.com)
2. Создайте новую таблицу
3. Назовите её: "Заявки на билеты LIBERTAD"

#### 2. Создание Google Apps Script

1. В таблице: **Расширения** → **Apps Script**
2. Удалите весь код
3. Скопируйте содержимое файла `google-apps-script.gs`
4. Вставьте в редактор
5. Нажмите **Сохранить**
6. Назовите проект: "Ticket Notifications Handler"

#### 3. Развертывание веб-приложения

1. Нажмите **Развернуть** → **Новое развертывание**
2. Выберите тип: **Веб-приложение**
3. Настройки:
   - **Описание**: "Ticket notification form handler"
   - **Запуск от имени**: Меня
   - **У кого есть доступ**: **Все**
4. Нажмите **Развернуть**
5. Авторизуйте доступ:
   - **Авторизовать доступ**
   - Выберите аккаунт
   - **Дополнительные настройки**
   - **Перейти на страницу "Ticket Notifications Handler" (небезопасно)**
   - **Разрешить**
6. **Скопируйте URL веб-приложения**

#### 4. Обновление конфигурации

Вставьте скопированный URL в `js/config.js`:

```javascript
const TICKET_CONFIG = {
    mode: 'collect_contacts',
    ticketSaleUrl: '',
    googleScriptUrl: 'https://script.google.com/macros/s/AKfycbz.../exec'  // Ваш URL
};
```

## Режим 2: Прямая продажа билетов

Используется когда билеты уже в продаже через внешнюю систему (Timepad, Kassir.ru и т.д.).

### Настройка:

```javascript
const TICKET_CONFIG = {
    mode: 'ticket_sale',
    ticketSaleUrl: 'https://timepad.ru/event/12345/',  // Ваша ссылка на продажу
    googleScriptUrl: ''  // Не используется в этом режиме
};
```

### Поведение:

- При клике на "Купить билет" пользователь перенаправляется на `ticketSaleUrl`
- Модальное окно с формой **не показывается**
- Ссылка открывается в новой вкладке

---

## Переключение между режимами

### Начало продаж билетов

Когда билеты поступили в продажу, измените конфигурацию:

**Было:**
```javascript
const TICKET_CONFIG = {
    mode: 'collect_contacts',
    ticketSaleUrl: '',
    googleScriptUrl: 'https://script.google.com/macros/s/.../exec'
};
```

**Стало:**
```javascript
const TICKET_CONFIG = {
    mode: 'ticket_sale',
    ticketSaleUrl: 'https://timepad.ru/event/12345/',
    googleScriptUrl: 'https://script.google.com/macros/s/.../exec'  // Можно оставить
};
```

### Возврат к сбору контактов

Если нужно вернуться к сбору контактов (например, для следующего спектакля):

```javascript
const TICKET_CONFIG = {
    mode: 'collect_contacts',
    ticketSaleUrl: 'https://timepad.ru/event/12345/',  // Можно оставить
    googleScriptUrl: 'https://script.google.com/macros/s/.../exec'
};
```

## Тестирование

### Режим сбора контактов:

1. Откройте сайт
2. Нажмите "Купить билет"
3. Должна открыться модальная форма
4. Заполните и отправьте
5. Проверьте Google Таблицу - должна появиться новая строка

### Режим прямой продажи:

1. Откройте сайт
2. Нажмите "Купить билет"
3. Должна открыться новая вкладка с системой продажи билетов
4. Модальное окно **не должно** появляться

## Устранение неполадок

### Форма не отправляется

- Проверьте URL в `googleScriptUrl`
- Откройте консоль браузера (F12) для ошибок
- Убедитесь, что скрипт развернут с доступом "Все"

### Данные не появляются в таблице

- Проверьте авторизацию скрипта
- Попробуйте создать новое развертывание
- Проверьте, что таблица не защищена от редактирования

### Кнопки не работают

- Убедитесь, что `js/config.js` загружается **перед** `js/main.js`
- Проверьте порядок скриптов в HTML:
  ```html
  <script src="js/config.js"></script>
  <script src="js/main.js"></script>
  ```

### Модальное окно не закрывается

- Нажмите Escape
- Кликните вне модального окна
- Нажмите крестик в правом верхнем углу

## Дополнительные возможности

### Email-уведомления при новой заявке

Добавьте в Google Apps Script триггер:

1. В редакторе Apps Script: **Триггеры** (иконка часов)
2. **Добавить триггер**
3. Функция: `onFormSubmit` (создайте её)
4. Тип события: **При изменении** → **При изменении**

Пример функции:
```javascript
function onFormSubmit(e) {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const lastRow = sheet.getLastRow();
  const data = sheet.getRange(lastRow, 1, 1, 4).getValues()[0];
  
  MailApp.sendEmail({
    to: 'admin@libertad-theatre.com',
    subject: 'Новая заявка на билеты',
    body: `Имя: ${data[1]}\nEmail: ${data[2]}\nТелефон: ${data[3]}`
  });
}
```

### Экспорт данных

Данные можно экспортировать:
- **Файл** → **Скачать** → CSV / Excel
- Использовать для email-рассылок
- Импортировать в CRM-системы

## Безопасность

- Google Apps Script работает от вашего имени
- Доступ "Все" безопасен - скрипт только добавляет данные в таблицу
- Не храните пароли или API-ключи в config.js
- Регулярно проверяйте таблицу на спам-заявки
