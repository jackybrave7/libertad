# Система продажи билетов - Краткая инструкция

## 🎯 Быстрый старт

### Файл конфигурации: `js/config.js`

Откройте файл и настройте один из двух режимов:

#### Режим 1: Сбор контактов (билеты еще не продаются)

```javascript
const TICKET_CONFIG = {
    mode: 'collect_contacts',
    ticketSaleUrl: '',
    googleScriptUrl: 'YOUR_GOOGLE_SCRIPT_URL_HERE'
};
```

**Что делать:**
1. Следуйте инструкциям в файле `TICKET_SYSTEM_SETUP.md`
2. Настройте Google Sheets и Apps Script
3. Вставьте URL скрипта в `googleScriptUrl`

#### Режим 2: Прямая продажа (билеты уже в продаже)

```javascript
const TICKET_CONFIG = {
    mode: 'ticket_sale',
    ticketSaleUrl: 'https://timepad.ru/event/12345/',
    googleScriptUrl: ''
};
```

**Что делать:**
1. Вставьте ссылку на страницу продажи билетов в `ticketSaleUrl`
2. Готово! Кнопки будут перенаправлять на эту страницу

## 🔄 Переключение режимов

### Когда начнется продажа билетов:

Измените в `js/config.js`:

```javascript
// Было:
mode: 'collect_contacts'

// Стало:
mode: 'ticket_sale'
ticketSaleUrl: 'https://ваша-ссылка-на-билеты.ru'
```

## ✅ Проверка работы

### Режим сбора контактов:
1. Нажмите "Купить билет"
2. Откроется модальное окно с формой
3. Заполните и отправьте
4. Проверьте Google Таблицу

### Режим прямой продажи:
1. Нажмите "Купить билет"
2. Откроется новая вкладка с системой продажи
3. Модальное окно не появляется

## 🆘 Помощь

Если что-то не работает:
1. Откройте консоль браузера (F12)
2. Проверьте порядок скриптов в HTML:
   ```html
   <script src="js/config.js"></script>
   <script src="js/main.js"></script>
   ```
3. Убедитесь, что `mode` в config.js установлен правильно
4. Смотрите подробную документацию в `TICKET_SYSTEM_SETUP.md`
