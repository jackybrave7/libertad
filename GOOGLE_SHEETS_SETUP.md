# Инструкция по настройке Google Sheets для сбора контактов

## Шаг 1: Создание Google Таблицы

1. Откройте [Google Sheets](https://sheets.google.com)
2. Создайте новую таблицу
3. Назовите её, например: "Заявки на билеты LIBERTAD"

## Шаг 2: Создание Google Apps Script

1. В открытой таблице перейдите в меню **Расширения** → **Apps Script**
2. Удалите весь код в редакторе
3. Скопируйте содержимое файла `google-apps-script.gs` из этого проекта
4. Вставьте код в редактор Apps Script
5. Нажмите **Сохранить** (иконка дискеты)
6. Дайте проекту имя, например: "Ticket Notifications Handler"

## Шаг 3: Развертывание веб-приложения

1. В редакторе Apps Script нажмите **Развернуть** → **Новое развертывание**
2. Нажмите на иконку шестеренки рядом с "Выберите тип"
3. Выберите **Веб-приложение**
4. Заполните настройки:
   - **Описание**: "Ticket notification form handler"
   - **Запуск от имени**: Меня (ваш email)
   - **У кого есть доступ**: Все
5. Нажмите **Развернуть**
6. Подтвердите разрешения:
   - Нажмите **Авторизовать доступ**
   - Выберите ваш Google аккаунт
   - Нажмите **Дополнительные настройки**
   - Нажмите **Перейти на страницу "Ticket Notifications Handler" (небезопасно)**
   - Нажмите **Разрешить**
7. **Скопируйте URL веб-приложения** - он понадобится на следующем шаге

## Шаг 4: Обновление JavaScript кода

1. Откройте файл `js/main.js` в вашем проекте
2. Найдите строку:
   ```javascript
   const GOOGLE_SCRIPT_URL = 'YOUR_GOOGLE_SCRIPT_URL_HERE';
   ```
3. Замените `'YOUR_GOOGLE_SCRIPT_URL_HERE'` на скопированный URL из предыдущего шага:
   ```javascript
   const GOOGLE_SCRIPT_URL = 'https://script.google.com/macros/s/YOUR_SCRIPT_ID/exec';
   ```
4. Сохраните файл

## Шаг 5: Тестирование

1. Откройте ваш сайт в браузере
2. Нажмите на любую кнопку "Купить билет"
3. Заполните форму и отправьте
4. Проверьте Google Таблицу - должна появиться новая строка с данными

## Структура данных в Google Sheets

Таблица будет содержать следующие колонки:
- **Дата/время** - автоматическая метка времени
- **Имя** - имя посетителя
- **Email** - email для уведомлений
- **Телефон** - телефон (необязательное поле)

## Обновление скрипта

Если вам нужно обновить код скрипта:

1. Откройте Apps Script редактор
2. Внесите изменения в код
3. Нажмите **Сохранить**
4. Перейдите в **Развернуть** → **Управление развертываниями**
5. Нажмите на иконку редактирования (карандаш)
6. Измените **Версию** на "Новая версия"
7. Нажмите **Развернуть**

## Устранение неполадок

### Форма не отправляется
- Проверьте, что URL скрипта правильно вставлен в `js/main.js`
- Откройте консоль браузера (F12) и проверьте наличие ошибок

### Данные не появляются в таблице
- Убедитесь, что скрипт развернут с доступом "Все"
- Проверьте, что вы авторизовали скрипт
- Попробуйте создать новое развертывание

### Ошибка CORS
- Это нормально при использовании `mode: 'no-cors'`
- Данные всё равно будут сохранены в таблице
- Проверьте таблицу, чтобы убедиться

## Дополнительные возможности

### Автоматические уведомления
Вы можете настроить триггеры в Apps Script для отправки email-уведомлений при добавлении новой строки.

### Экспорт данных
Данные можно экспортировать из Google Sheets в CSV, Excel или другие форматы через меню **Файл** → **Скачать**.
